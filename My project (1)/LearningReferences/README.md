# Learning References

This folder is intentionally outside `Assets`, so reference projects do not
compile into the current Unity project or overwrite its `ProjectSettings`.

## UnityGameFramework

- Current project package: `com.jiangyin.gameframework.latest@2022.1.1`
- Registry: `https://package.openupm.com`
- Official demo: https://github.com/EllanJiang/StarForce
- License: MIT

Use StarForce as the main architecture reference for Procedure, UI, Event,
Resource, Entity, ObjectPool, and DataTable usage.

## WaveOfTheFist

- Local path: `LearningReferences/WaveOfTheFist`
- Source: https://github.com/jampamatos/wave_of_the_fist
- License: MIT
- Purpose: 2D side-scrolling beat-em-up gameplay and asset reference.

Treat it as reference material first. Move only selected scripts or assets into
the real project after deciding how they should fit into UnityGameFramework.
